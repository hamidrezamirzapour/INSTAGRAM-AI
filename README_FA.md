# عامل Reels از ترندهای AI و فناوری

این پروژه RSS گوگل ترندز در US/GB/CA/AU را بررسی می‌کند، برای پذیرش موضوع حداقل دو منبع خبری مستقل می‌خواهد و فقط از تیترها برای تولید پیش‌نویس انگلیسی استفاده می‌کند. متن مقاله یا رسانه دارای حق نشر scrape نمی‌شود؛ خروجی کارت‌های متنی اصیل و ویدیوی عمودی حدود ۱۸ ثانیه است. اگر تیترها برای یک نکته معنادار کافی نباشند، موضوع رد می‌شود. تیتر به‌تنهایی راستی‌آزمایی خبر نیست و بازبینی انسانی لازم است.

## راه‌اندازی
1. Python 3.11+، `pip install -r requirements.txt` و FFmpeg لازم است. تست آفلاین: `python -m unittest discover -s tests -v`.
2. کلید Gemini AI Studio را در GitHub Actions Secret با نام `GEMINI_API_KEY` ذخیره کنید. مدل قابل تنظیم است و پیش‌فرض `gemini-3.1-flash-lite` است (`GEMINI_MODEL`). دسترسی مدل، سهمیه رایگان و امکان منطقه‌ای/حساب متغیر است؛ رایگان بودن تضمین‌شده نیست. پروژه دیگر به مدل قدیمی 2.5 Flash-Lite پیش‌فرض نمی‌کند.
3. برای انتشار، حساب Instagram Professional متصل به Facebook Page، اپ و مجوزهای جاری Meta لازم است. Secrets: `IG_USER_ID`, `PAGE_ACCESS_TOKEN`. هرگز رمزها را داخل مخزن نگذارید.
4. در Settings → Pages منبع را روی **GitHub Actions** قرار دهید. workflow ویدیو را به Pages deploy می‌کند و پس از بررسی URL عمومی، در حالت انتشار زنده سراغ Graph API می‌رود.
5. Variables: `AUTO_PUBLISH=false`، `POST_EVERY_DAYS=2` (فقط ۱ یا ۲). زمان اجرای روزانه 15:17 UTC است. ابتدا دستی اجرا کرده، artifact `reel-preview`، تیترها و ویدیو را بررسی کنید؛ سپس در صورت تأیید خودتان `AUTO_PUBLISH=true` کنید. در خطای انتشار state pending برای جلوگیری از انتشار تکراری می‌ماند و پیش از تلاش مجدد باید دستی بررسی شود.

## مشخصات ویدیو و محدودیت هزینه
MP4 با H.264، اندازه 1080×1920، 30fps، AAC 48kHz و صدای سکوت، حدود ۱۸ ثانیه ساخته می‌شود. مشخصات Instagram API برای Reel مدت ۳ ثانیه تا ۱۵ دقیقه را مجاز می‌داند؛ پس ۱۸ ثانیه در بازه مدت قرار دارد. هشدار قبلی حداقل سه دقیقه نادرست بود. سایر محدودیت‌های جاری API و صلاحیت حساب ممکن است تغییر کنند. هزینه صفر تضمین نمی‌شود؛ سهمیه Gemini، GitHub و Meta را بررسی کنید. هیچ تست شبکه/API در این اصلاح انجام نشده است.

راهنمای کامل انگلیسی در `README.md` است.
